# DSH 多引擎搜索 · DSH Multi Web Search

**中文名 / Chinese name：** DSH 多引擎搜索
**English name：** DSH Multi Web Search

**中文简介：** 给 DSH 的 web 搜索 seam 增加多个搜索提供商（Bocha、Tavily、Brave、Exa、Perplexity、智谱、MiniMax、SearXNG、DuckDuckGo）的宿主插件，没有客户端界面。
**English description：** Host-only plugin adding extra web-search providers (Bocha, Tavily, Brave, Exa, Perplexity, Zhipu, MiniMax, SearXNG, DuckDuckGo) to DSH’s web search seam; no client UI.

**状态 / Status：** 实验性 / Experimental（host-only，需手动接入 / manual wiring）

**安装 / Install：** 用 DSH 自带的「插件管理 → 添加插件」，输入本目录的绝对路径；或使用仓库 `dist/` 中对应的 `.tgz`。
Use DSH’s built-in **Plugins → Add plugin** and paste this folder’s absolute path; or install the matching `.tgz` from the repo’s `dist/`.
