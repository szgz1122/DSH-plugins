# DSH 会话恢复 · DSH Session Unarchive

**中文名 / Chinese name：** DSH 会话恢复
**English name：** DSH Session Unarchive

**中文简介：** 早期会话恢复的宿主侧能力，无客户端界面。
**English description：** Early host-side session-unarchive helper; no client UI.

**状态 / Status：** 历史版本 / Legacy

**安装 / Install：** 用 DSH 自带的「插件管理 → 添加插件」，输入本目录的绝对路径；或使用仓库 `dist/` 中对应的 `.tgz`。
Use DSH’s built-in **Plugins → Add plugin** and paste this folder’s absolute path; or install the matching `.tgz` from the repo’s `dist/`.

## 说明 / Notes

本插件为早期/宿主侧插件，建议先阅读源码再安装。
This is an early/host-side plugin; read the source before installing.
